# Bundled Python wheels

These pinned, pure-Python wheels let `GISAID_SUBMISSION` reuse the official
legacy `.xls` templates without downloading packages during an analysis:

- xlrd 2.0.1 — BSD license
- xlwt 1.3.0 — BSD license
- xlutils 2.0.0 — MIT license

The files are unmodified distributions downloaded from PyPI. Project pages:
https://pypi.org/project/xlrd/2.0.1/,
https://pypi.org/project/xlwt/1.3.0/, and
https://pypi.org/project/xlutils/2.0.0/.
